# Web Designing Workshop (BCS-353)

This folder contains the lab work based on the attached GL Bajaj Web Designing manual.

## Experiments

1. `online-bookstore/` - framed home page, login, catalogue, cart, and branch catalogue pages.
2. `online-bookstore/login.html` - login page.
3. `online-bookstore/catalogue.html` - catalogue table with cover, author, publisher, price, and cart action.
4. `online-bookstore/cart.html` - cart page.
5. `registration/registration.html` - registration form with all requested controls.
6-7. `registration/registration.html` and `registration/validation.js` - client-side validation for name, password, email, and phone.
8-9. `css-lab/sample.html` and `css-lab/style.css` - selectors, fonts, backgrounds, repeat behavior, link states, and cursor styles.
10. `portfolio/` - a responsive personal portfolio implementing HTML, CSS, and JavaScript.

Open `online-bookstore/home.html` to view the bookstore experiment and `portfolio/index.html` for the selected topic.
